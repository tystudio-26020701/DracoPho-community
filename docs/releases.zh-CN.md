# 发版说明

### 26.8.1.1

> **Mark Shot 社区版**——维护版本，修复设置窗口"未保存修改"感知与多屏冻结
> 行为，并新增 10 个语言版本的 README 与文档修复。

#### 修复

**设置窗口"未保存修改"感知**
- **确定性脏状态跟踪**：全部设置控件的值变更信号（下拉框选择、开关切换、
  数值框、文本框、快捷键框）直接驱动"未保存修改"标记，不再依赖事件是否落在
  设置窗口内。此前下拉框弹出层选择会跳过刷新——改值不显示"未保存"、改回后
  仍阻拦关闭，假阴性/假阳性两种问题均已消除。
- **取色器刷新**：通过模态取色对话框修改默认标注颜色或贴图边框颜色后，会
  在对话框返回时正确刷新脏标记（此前颜色应用不产生值信号）。
- **精度归一化基线**：角半径、阴影透明度、翻译温度与贴图边框宽度按控件可
  表达精度归一化，手写小数配置不再在打开设置窗口时立即显示为"未保存"。

**多屏冻结范围**
- **其他显示器保持冻结背景**：使用默认的"冻结全部屏幕"范围时，在某台显示器
  完成选区后，其余显示器的覆盖层保持冻结且完全不可操作（吞掉鼠标/键盘/滚轮/
  快捷键并隐藏工具栏），而不是关闭它们导致屏幕恢复可操作。会话随主选区窗口
  关闭而结束；独立关闭冻结背景不再打断正在进行的编辑。

**文档**
- README 新增 10 个语言版本（繁體中文、日本語、한국어、Русский、Italiano、
  العربية、Français、Deutsch、Español、Português），存放于 `READMEs/` 子目录，
  根 README 提供语言切换索引。
- 修复全部 12 份用户手册中"问题提交指南"的相对链接。

### 26.8.1.0

> **Mark Shot 社区版**——采用新版本号格式（年.月.版.微调）的首个发布版本，
> 基于原上游项目 `jswysnemc/mark-shot` 开发。发布包涵盖 Linux `.tar.gz` /
> `.deb` / `.rpm` / `.AppImage` / `.flatpak`、Windows `.zip` 与 Arch 包。

#### 新功能

**无头截图 CLI**
- `--capture-to <path>`：不打开标注界面直接截图并写入 PNG，同时向 stdout 输出紧凑 JSON 摘要；复用全部交互截图后端（QScreen、xdg-desktop-portal、PipeWire、grim、KWin/GNOME 助手、Windows Graphics Capture），画质与交互截图一致。
- `--region x,y,w,h` 截取逻辑屏幕区域；`--display <name>` 按显示器名选择并支持重复以一次截取多个显示器；`--include-cursor` 将鼠标指针绘入画面；`--output-name` 指定生成文件名；`--list-displays` 以 JSON 列出可用输出。
- `--list-windows` 列出可见窗口（index/id/title/class/instance/geometry，可选 zOrder），支持 Wayland（GNOME/KDE/Hyprland/niri）与 X11；`--window <selector>`（可重复，支持 `auto/id/title/class/index` 匹配，`<selector>@x,y,w,h` 截取窗口内组件子区域）截取任意窗口。
- `--capture-destination inline|file|stage|clipboard`：inline 直接返回 base64 不写文件不碰剪贴板；file 写入 `--capture-to`；stage 写入 `$TMPDIR/mark-shot-staging`；clipboard 仅在显式指定时写入系统剪贴板。默认去向与剪贴板权限可在 设置 → 存储 中配置（口令二次确认，默认关闭）。
- 无头模式不建窗口、不弹交互 portal 对话框、即取即退，捕获前后窗口列表保持一致。

**文字标注控制**
- 字体面板提供精确字号输入（20–300pt，支持 24.5 等浮点精度）、字体族列表、粗体/斜体开关；对新建文字、行内编辑器和已有标注均生效，并通过 `annotation-state.json` 跨会话持久化。
- 新建标注默认字号由 63pt 修正为常规 20pt。

**设置与界面**
- **多语种界面**：12 种界面语言——英语、简体/繁体中文、日语、韩语、俄语、意大利语、阿拉伯语（从右到左布局）、法语、德语、西班牙语、葡萄牙语；跟随系统区域或 `MARK_SHOT_LANG` 环境变量，可在 设置 → 通用 中即时切换。
- **未保存修改保护**：分类显示未保存标记，页脚与标题提示待保存编辑；关闭时询问 保存并关闭 / 放弃并关闭 / 继续编辑（含 Escape 键路径）。
- **关于页面**：位于"高级"下方，展示软件图标、版本号、社区版仓库链接、公司 Logo，以及对原上游项目及其作者、贡献者的致谢。
- **设置滚轮防护**：悬停下拉框、数值框和滑块时滚动滚轮将滚动页面而不再篡改控件值；源码级滚轮抑制器保证无论焦点状态都生效。
- **滚轮精确滚动**：分数增量跨事件累积（对齐 Qt 原生累加器）；Ctrl/Shift + 滚轮整页滚动；惯性阶段干净复位。
- **分栏还原配置**：每个设置栏目与页面都提供"还原"按钮；高级页另提供二次确认的"还原原始设置"。
- **快捷键录入防护**：拒绝纯修饰键与危险键，全局快捷键要求至少一个修饰键或功能键，页面内重复快捷键会被提示，默认 Escape 取消快捷键不再被清空。

**系统集成**
- **X11 原生全局快捷键**：X11/Xorg 会话用 `xcb_grab_key`（含 NumLock/CapsLock 变体与原生事件分发），Wayland 走 portal；修饰键掩码按实时键盘映射解析，`altwin:swap_alt_win` 与自定义 xmodmap 布局可用，键盘映射变更后自动重新抓取。
- **F25–F35 功能键**：快捷键现一致支持 F25–F35（UI、X11 keysym 查找与 portal 触发）。
- 截图/标注覆盖层在 Windows 与 X11 下不再出现在任务栏与 Alt-Tab。
- 区域选择默认冻结全部显示器，并支持 X11/Windows 跨屏选区。

#### Bug 修复

- **Linux 截图后整屏花屏闪烁/抖动（过一会儿恢复）**：覆盖层在 Wayland 上不再做延迟 1px 尺寸往返（resize(w−1) 再 resize(w)）——1px 尺寸差会让合成器在全屏直扫与常规合成间反复切换，双屏/分数缩放下表现为整屏闪烁抖动与短暂花屏；现在覆盖层一次性放置到精确屏幕尺寸，映射后不再抖动尺寸。
- **Wayland 焦点争夺闪烁**：全屏覆盖层显示后不再调用 `raise()`/`activateWindow()`，并设置 `WA_ShowWithoutActivating`，避免与 GNOME 形成"焦点反复得失"循环。
- **覆盖层绘制抖动与阴影伪影**：截图覆盖层设置 `WA_OpaquePaintEvent` + `WA_NoSystemBackground`（合成器不再先清背景再画内容，避免 expose/重排时的双重绘制闪烁）与 `NoDropShadowWindowHint`（全屏覆盖层不进入阴影合成路径）；滚动截图覆盖层同步补上无阴影标志。
- 设置窗口未聚焦数值框/下拉框/滑块被滚轮滚动误改（Qt 6 无焦点也响应滚轮的内建行为）。
- 设置滚轮防护因重入事件派发导致段错误（Qt 6.11 手势管理器无重入保护）。
- 关于页字面 `%1` 占位符残留、页面无法滚动与 Logo 截断。
- 打开设置不再覆盖 `MARK_SHOT_LANG` 会话覆盖值。
- 默认 Escape 取消快捷键在配置重载时不再被静默清空。
- 文字字号映射与默认值修正（63pt → 20pt）。
- 窗口悬停框选 z-order 判定、未知 Wayland 会话脚本选择错误；自定义检测命令不再被覆盖。
- 无头截图边界场景（输出命名、几何处理）。
- 无头剪贴板持久化挂起（分离所有者进程 + 重定向 stdio；无头模式跳过 Wayland `QClipboard::setImage` 所有权往返）。
- 无 PipeWire 头文件的环境可编译（`HAVE_PIPEWIRE` 保护）。

#### 文档

- 用户手册支持 12 种语言。
- 新增无头 CLI 专章（全屏/多屏/窗口/组件截图、四种去向、剪贴板策略）与窗口悬停框选说明。
- 声明支持 Ubuntu 26.04 LTS 并文档化多屏无头截图。
- README 新增对原上游项目、其贡献者及所依赖开源项目的致谢。

- **Wayland 贴图窗口定位**：抽出 layer-shell 几何计算并改进 resize 控制器，修复贴图窗口在多屏或屏幕外的放置问题。

### 0.1.29

- **放大镜双框独立调节**：放大镜的内层取景框与外层透镜各自带有 resize 把手，矩形透镜每框 8 个角/边把手，圆形透镜每框 4 个上下左右把手。调整任一框时按 `magnifierScale` 联动另一框，倍率始终保持不变；平移单框时另一框保持原位。
- **矩形高亮与反色风格**：矩形工具新增风格选择器，提供三种模式——`描边`（原有的描边或填充矩形，可选圆角）、`高亮`（以 `CompositionMode_Multiply` 与半透明填充实现的荧光笔式覆盖）、`反色`（对矩形覆盖区域的像素做 RGB 反相，并保留外轮廓作为视觉提示）。在 `高亮` 与 `反色` 模式下会自动隐藏填充开关与圆角滑块。
- **工具默认值跨会话持久化**：标注工具默认值（颜色、不透明度、各工具笔宽、矩形填充/圆角/风格、放大镜倍率与形状、箭头/荧光笔/数字步骤风格、文本字体、文字背景色）会通过独立的 `annotation-state.json` 跨会话保留。写盘通过 `QSaveFile` 原子提交，并在每个修改默认值的入口触发后立即写入。

### 0.1.28

- **可配置图片剪贴板策略**：新增 `clipboard.image.mode` 配置，支持 `image/png`、`url` 与 `threshold` 三种模式。默认使用直接 `image/png` 剪贴板数据，以改善办公套件和浏览器输入框的贴图兼容性，同时仍可通过 `thresholdM` 将大图切换为文件 URL 模式。
- **运行时默认配置创建**：程序启动时如果缺少 `config.json`，会自动创建默认配置文件，并写入新的剪贴板默认配置。
- **Shift 约束直线绘制**：绘制直线、箭头或直线模式荧光笔时，按住 `Shift` 会将线条吸附到水平、垂直或 45 度方向。

### 0.1.27

- **直线与箭头多骨架点编辑**：支持在直线和箭头标注上添加、拖拽、以及删除多个骨架点（控制点）。路径采用连续二次贝塞尔曲线拟合，并确保尖端精准落于终点。
- **快捷键与交互优化**：增强了键盘和滚轮的交互（例如使用 Backspace/Delete 键删除选中的骨架控制点），并将输入快捷键处理逻辑进行了模块化拆分。

### 0.1.26

- **自定义保存路径与占位符支持**：引入了截图保存路径模板和目录模板机制（`save.pathTemplate` 和 `save.directoryTemplate`），支持包括 `{pictures}`, `{datetime}`, `{selection.width}` 以及自定义日期格式 `{datetime:yyyy-MM-dd}` 等 30 多个动态占位符，实现灵活的文件命名和分类存储。
- **KDE KWin 截屏控制开关**：新增 `capture.wayland.kde.kwinScreenshot.enabled` 配置项，允许关闭或开启 KDE 限制级 API 截图方式，便于进行截图后端的回退调试。
- **文档优化与内容折叠**：精简重构了用户手册，包括对 KDE 繁杂的 KWin 授权文件进行了折叠处理，减少无关信息的视觉干扰。
